## 2025-05-22 - Optimizing Home Page Performance
**Learning:** Lifting static data arrays (like locations or categories) outside of React component functions prevents them from being re-allocated on every render cycle. This avoids unnecessary memory churn and potential referential inequality issues if those arrays are passed as props to memoized components. Additionally, memoizing derived state from global context (like filtered product lists) ensures that expensive filter operations only run when the underlying data or search query actually changes.
**Action:** Always check for static constants defined inside components and move them to the module level. Use `useMemo` for any filtering or sorting of lists derived from context or state. Use Next.js `<Image />` with `priority` for above-the-fold content to improve LCP.
